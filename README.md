# TVhiroba

テレビ視聴、外部入力の視聴、各Webサービスへの外部リンクを、ひとつのホーム画面にまとめるWebアプリです。

- **テレビ視聴**：mirakc / Mirakurun互換サーバーに接続し、チャンネルや現在・次の番組を確認しながらライブ映像を視聴できます。
- **外部入力の視聴**：ブラウザを開いているPCに接続したUVCキャプチャーデバイスなどの映像・音声を視聴できます。
- **外部リンクの配置**：好きなWebサイトへのリンクをホームに配置できます。リンクごとに、同じタブで開くか新しいタブで開くかを選べます。

## 必要なもの

- Node.js 20以降とnpm
- 接続可能なmirakc / Mirakurun互換サーバー（現在の初回セットアップでは登録が必要です）
- テレビ再生に必要なMSE・WebAssemblyに対応したブラウザ
- 外部入力を使う場合は、ブラウザから利用できる映像入力デバイスと、必要に応じて音声入力デバイス

テレビサーバーは別途用意してください。TVhiroba自体には放送の受信機能はありません。

## 起動

プロジェクト直下で実行します。

```sh
npm install
npm run dev
```

開発時は `http://localhost:5173` を開きます。Viteが画面を配信し、APIは同じPCのNode.jsサーバー（ポート4174）へ中継します。

本番向けにビルドして起動する場合は、次を実行します。

```sh
npm run build
npm start
```

Node.jsサーバーが画面とAPIを `http://localhost:4174` で配信します。ポートは環境変数 `PORT` で変更できます。

## 初回セットアップ

初めて開くと、次の順番で設定します。

1. **テレビサーバー**：mirakc / MirakurunのベースURLを入力し、接続して保存します（例：`http://192.168.1.10:40772`）。
2. **外部リンク**：ホームに置くリンクの名前・URL・開き方を登録します。使わない場合はスキップできます。
3. **外部入力**：カメラ・マイクへのアクセスを許可し、映像入力と音声入力を選びます。音声は「音声なし」も選べます。使わない場合はスキップできます。

設定後はホームが表示されます。いずれの設定も、ホームの「設定」から変更できます。

## 使い方

### テレビを見る

ホームの「テレビ」を開き、放送種別とチャンネルを選びます。選局一覧には、現在の番組名が取得できているサービスを表示し、現在の番組の放送時間と次の番組名を確認できます。番組情報が取得できない場合は、テレビサーバー側の番組情報を確認してください。一覧の更新ボタンでチャンネル・番組情報を再取得できます。

放送種別と種別ごとの選局はブラウザに保存され、次にテレビ画面を開いたときに復元されます。視聴中は画面のクリックで操作表示を切り替えられます。

キーボードでも操作できます。

| キー | 操作 |
| --- | --- |
| `1`〜`9` / `0` / `F11` / `F12` | 表示中の放送種別のリモコン番号1〜12を選局（番号がある場合） |
| `PageUp` / `PageDown` | 表示中の一覧で次／前のチャンネルを選局 |
| `←` / `→` | チャンネルボタン間のフォーカスを移動 |

### 外部入力を見る

映像入力を登録すると、ホームに「外部入力」が表示されます。開くと、選択したデバイスの映像・音声の取り込みを開始します。ホームに戻ると取り込みを停止します。デバイスが切断された場合は、接続を確認して「再試行」を押してください。

キャプチャーデバイスは、TVhirobaのサーバーではなく、ブラウザを開いているPCに接続します。外部入力にはHTTPSまたはlocalhostでのアクセスが必要です。LAN内のHTTPアドレスでは利用できません。

### 外部リンクを配置する

「設定」の「外部リンク」から、リンク名とHTTP／HTTPSのURLを登録します。「新しいタブで開く」を選ぶと別タブで開き、選ばなければTVhirobaと同じタブで移動します。

複数のリンクを登録でき、保存した順にホームへ表示されます。不要なリンクは削除して保存できます。

## 設定の保存先

| 設定 | 保存先 |
| --- | --- |
| テレビサーバーの接続先 | サーバー上の `server/data/config.json` |
| 外部入力デバイス・外部リンク・放送種別・選局 | ブラウザのlocalStorage |

ブラウザ側の設定は、ブラウザやアクセス先のオリジンごとに保存されます。別のブラウザやURLで開く場合は再設定が必要です。

## 再生の仕組み・制約

テレビサーバーのMPEG-TSストリームをNode.jsサーバー経由でブラウザに渡し、同梱の[`mpeg2toh264`](vendor/mpeg2toh264-player/NOTICE.md)プレイヤーでH.264/AACのfragmented MP4へ変換してMSEで再生します。MPEG-2 VideoからH.264への変換は、ブラウザ内のWorker／WebAssemblyで行います。

同梱プレイヤーではAAC-LC音声とMPEG-2 4:2:0映像が対象です。再生中の解像度・走査方式の切り替えなどには制約があります。画面に放送種別が表示されていても、その種別のすべての映像・音声形式を再生できるとは限りません。テレビ・外部入力ともに、ブラウザの自動再生やデバイス権限の制限が適用されます。

## 開発向け情報

### チャンネルAPI

`GET /api/tvhiroba/channels` は、テレビサーバーのチャンネル・サービス・番組一覧をまとめ、サービスごとの現在・次の番組情報を返します。画面では、そのうち現在の番組名があるサービスを選局一覧に表示します。

### 画面のパス

| パス | 画面 |
| --- | --- |
| `/` | ホーム |
| `/tv` | テレビ視聴 |
| `/input` | 外部入力の視聴 |
| `/settings` | 接続先・外部リンク・外部入力の設定 |
| `/setup` | 初回セットアップの案内 |
| `/setup/connection` | テレビサーバーの接続設定 |
| `/setup/input` | 外部入力の設定（スキップ可能） |
| `/setup/links` | 外部リンクの設定（スキップ可能） |

URLへの直接アクセス・再読み込み・ブラウザの戻る／進むに対応します。未設定の項目がある場合はセットアップへ移動し、完了後は元の画面に戻ります。外部入力が未登録で `/input` を開いた場合は設定画面へ移動します。

開発用Viteと本番用Node.jsサーバーは、画面パスへのアクセスに `index.html` を返します。別のWebサーバーで配信する場合も、`/api` と静的ファイル以外の画面パスを `index.html` にフォールバックさせてください。
